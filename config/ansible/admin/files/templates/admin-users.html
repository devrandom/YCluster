Users

Accounts live in the cluster IdP. Invite creates a single-use enrollment link for a new account (hand it over out-of-band — no email is sent); reset link issues a one-time password (re)set for an existing one. Admin grants full access to these admin pages. Manager grants view access plus project-scoped operations: edit Notes, invite, and issue reset links — but only for projects they're authorized to (set via `ycluster user manager-projects`).
